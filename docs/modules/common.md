# common

상태: 초안 · 갱신: 2026-11-06

## 1. 책임 (Responsibility)
- 여러 모듈이 함께 쓰는, 업무 규칙이 없는 값 타입을 제공한다.

## 2. 소유 대상 (Ownership)
- 금액 `Money`: 원 단위 정수. 소수점 이하가 없다.

**넣는 기준.** 다음을 모두 만족할 때만 둔다.
1. 두 개 이상의 모듈이 실제로 쓴다.
2. 특정 모듈의 업무 규칙을 담지 않는다. 예: 본인부담금 계산, 끝전 처리 규칙은 `billing`에 둔다.
3. 다른 모듈을 의존하지 않는다.

**넣지 않는 것.** 서비스, 리포지토리, 엔티티, 특정 모듈의 ID 타입(예: 내원 건 ID는 `reception`), "어디 둘지 애매한 것".

## 3. 공개 계약 (Public Contract)

| 종류 | 이름 | 내용 | 보장 수준 |
| :--- | :--- | :--- | :--- |
| 값 | `Money` | 금액. 더하기, 빼기, 비교 | 바뀌지 않는 값이다. 음수 허용 여부는 쓰는 쪽의 규칙으로 판단한다. |

- 발행하는 이벤트: 없음

## 4. 모듈 의존성 (Dependencies)
- 없음. 모든 모듈이 이 모듈에 의존할 수 있다.

## 5. 명시적 비책임 (Non-Goals)
- 금액에 관한 업무 규칙(본인부담 계산, 끝전 처리, 환불 배분). 각각 `billing`, `payment`에 둔다.
- 범용 유틸리티 모음
