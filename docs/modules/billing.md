# billing

상태: 초안 · 갱신: 2026-11-06

## 1. 책임 (Responsibility)
- 주어진 오더 항목들을 내원 건의 자격과 진료일의 수가로 계산해 산정을 남긴다(F-03).
- 재산정도 같은 계산으로 한다(F-04.a, F-04.d, F-06.c).
- 끝전 처리는 산정 합계에 한다.
- **무엇을 산정할지는 고르지 않는다.** 산정 대상은 `payment`가 정해서 넘긴다.

## 2. 소유 대상 (Ownership)
- [산정](../domain/02-glossary.md#산정) `Invoice`(산정 합계 `total` 포함), [산정 내역](../domain/02-glossary.md#산정-내역) `InvoiceLine`
- [본인부담금](../domain/02-glossary.md#본인부담금)·[공단부담금](../domain/02-glossary.md#공단부담금) 계산, [끝전 처리](../domain/02-glossary.md#끝전-처리) 규칙

## 3. 공개 계약 (Public Contract)

| 종류 | 이름 | 입력 | 결과 | 보장 수준 |
| :--- | :--- | :--- | :--- | :--- |
| 명령 | `Billing.calculate` | 내원 건, 오더 항목들(수가 항목, 수량) | 산정 | 같은 입력이면 같은 결과다. 자격은 그 시점의 가장 나중 기록, 수가는 진료일 기준이다. |
| 조회 | `Billing.recalculate` | 내원 건, 남은 오더 항목들 | 재산정 합계 | 산정을 남기지 않고 합계만 돌려준다. 환불액 = 현재 수납액 − 재산정 합계(A-19)는 `payment`가 계산한다. |
| 조회 | `Invoices.get` | 산정 | 산정 내역과 합계 | 산정은 만든 뒤 바뀌지 않는다. |

- 발행하는 이벤트: 없음

## 4. 모듈 의존성 (Dependencies)
- `master`: 진료일의 수가, 급여 구분
- `reception`: 내원 건의 진료일과 자격 기록

## 5. 명시적 비책임 (Non-Goals)
- 산정 대상 선택(`payment`)
- 수납, 환불액 계산(`payment`)
- 보험 청구, 야간·공휴일 가산(범위 밖)

## 6. 관련 규칙
- 흐름: F-03
- 가정: A-06, A-19
- 미정: 끝전 단위(용어집 8절), ADR-0001
